# 🧬 DNA & Protein Sequence Analyzer

An interactive Web Application built with **Python**, **Streamlit**, and **Biopython** that performs real-time sequence analysis, transcription, translation, and amino acid distribution visualization.

[![Streamlit App](https://ayhjtpu4l8nvurpc6yhwgi.streamlit.app/)

---

##  Overview

The **DNA & Protein Sequence Analyzer** simplifies basic bioinformatics workflows. Users can input standard DNA sequences (or raw FASTA strings) to quickly extract key genomic metrics, translate nucleotide sequences into functional protein chains, and visualize amino acid frequencies.

##  Key Features

- **📊 Basic Sequence Analysis:** Instant calculation of sequence length (bp) and GC-Content percentage.
- **🔄 Transcription & Translation:** Automatically converts DNA → RNA → Amino Acid (Protein) sequences.
- **📈 Interactive Visualization:** Dynamic bar charts showcasing amino acid frequencies in translated proteins.
- **⚠️ Input Validation:** Automatic error detection for non-genomic characters.

## 🛠️ Built With

- **Python**
- **Streamlit** – Web Application Framework
- **Biopython** – Computational Molecular Biology Tools
- **Pandas** – Data Handling & Visualization
